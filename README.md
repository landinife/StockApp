# StockApp

Control de stock de planta (Pañol, Aceros, No ferrosos, Plásticos y Componentes).
App web para PC y teléfono, con datos en Firebase (proyecto `tpfapps-5f226`).

## Carpetas
- `docs/` → la app web. GitHub Pages la publica desde acá.
- `firestore.rules` → copia de referencia de las reglas de Firestore (compartidas con ViajesApp). Las reglas reales se cambian en la consola de Firebase.
- `android/` → (más adelante) la app de Android.

## Actualizar la app
Reemplazar los archivos de `docs/` y confirmar el cambio (commit). GitHub Pages se actualiza solo en uno o dos minutos.
